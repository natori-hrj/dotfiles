# dotfiles

Personal dotfiles for my ThinkPad running Omarchy.

## Enviroment

- OS: Omarchy / Arch Linux
- WM: Hyprland
- Terminal: Ghossty
- Editor: Neovim
- Shell: Zsh


## Setup

This repository is managed with GNU Stow.

```bash
```bash
git clone git@github.com:natori-hrj/dotfiles.git ~/dotfiles
cd ~/dotfiles
stow <package>
```
