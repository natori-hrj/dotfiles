# commands/delegate.md
---
name: delegate
description: タスクを最適なモデルのサブエージェントに委譲する（コスト/品質最適化）
---

引数で渡されたタスクを、`model-routing` skill の判断基準に従って最適なモデルのサブエージェントに委譲する。

手順:

1. `model-routing` skill を読み込む（未読の場合）
2. タスクを分類する:
   - 探索・網羅調査・一覧化 → `haiku`（Explore agent、必要なら複数並列）
   - 実装・テスト・リファクタリング → `sonnet`
   - 設計・複雑なデバッグ・セキュリティ・検証 → `opus`
   - 判断がつかない → model省略（セッションのモデルを継承）
3. 選んだモデルと理由を1行でユーザーに報告してから Agent tool で起動する
4. 独立したサブタスクに分割できる場合は、1メッセージで複数エージェントを並列起動する
5. 結果を検証してから統合・報告する（安いモデルの出力ほど検証を厚く）

引数がない場合は、直前の会話のタスクを対象とする。それもなければ何を委譲するか質問する。
